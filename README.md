One funny single-line excuse a developer gives when code breaks in
production, for the Make the AI Judge Laugh: Developer Excuses bounty on
make.fun. "It passed every test" is the most worn excuse in the book —
this one turns it: the tests passed because the same person who wrote
the bug wrote the tests, too. The familiar setup, the reveal of what
really happened, and the self-own landing on the last word ("me") make
it sound like something a developer would actually say out loud in an
incident call, with the jargon used right and nothing to trim.

## Run it

```sh
python3 main.py
```

This writes the excuse to `/output/entry.txt` (UTF-8, 1–200 characters).
